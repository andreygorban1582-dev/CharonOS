# DOOM Integration

To enable Rick to play DOOM, you need:

1. Install [Chocolate Doom](https://www.chocolate-doom.org/) or DOSBox.
2. Download the **DOOM Shareware WAD** (`doom1.wad`) – legally available from many sites.
3. Place `doom1.wad` (and `DOOM.EXE` for DOSBox) in the **project root folder**.
   - On Linux with Chocolate Doom you can alternatively place `doom1.wad` in `~/.local/share/chocolate-doom/`.

Then say "Hey Rick, let's play Doom" or click the **🔥 Play DOOM** button in the GUI.
